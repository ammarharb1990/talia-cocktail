# Talia Cocktail — نظام إدارة المحل

نظام إدارة محل كوكتيل وعصائر: إدخال يومي، مبيعات، مشتريات، موردون، مصاريف، صندوق، عمال وسلف، حساب شركة فخفخينا، مستحقات، وتقارير.

- افتح `index.html` في المتصفح للتشغيل.
- للتعديل افتح هذا الفولدر في **Claude Code**. ملف `CLAUDE.md` يشرح النظام وقواعده المحاسبية.
- الاختبار: `python tests/test_app.py` (يحتاج Playwright).
